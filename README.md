## 💻 หัวข้อการเรียนรู้ภาคปฏิบัติ (Core Concepts)

- [x] โครงสร้างพื้นฐานของภาษา C และ Preprocessor Directives (`#include`, `#define`)
- [x] ระบบตัวแปร ชนิดข้อมูลพื้นฐาน และการจัดสรรหน่วยความจำ (Stack / Heap)
- [x] ตัวดำเนินการทางคณิตศาสตร์ ตรรกศาสตร์ และระดับบิต (Bitwise Operations)
- [x] โครงสร้างการตัดสินใจและการวนซ้ำ (`if-else`, `switch`, `for`, `while`, `do-while`)
- [x] การจัดการฟังก์ชัน พารามิเตอร์ และการคืนค่า (Pass-by-value / Pass-by-reference)
